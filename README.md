A production-ready starter repository featuring standard **CRUD** operations, advanced authentication, and containerization using **NestJS**.

---

## Features ✨

### 🔐 Authentication & Security
- **RBAC with JWT:** Secure Role-Based Access Control using JSON Web Tokens.
- **GitHub OAuth 2:** Social login integration for seamless user onboarding.
- **Custom Decorators:** Simplified user extraction and role checks (e.g., `@CurrentUser()`, `@Roles('admin')`).

### 🛠 Core Functionality
- **REST API:** Adheres to strict RESTful standards.
- **Global Exception Filter:** Standardized error handling responses across the application.
- **Validation:** Request DTO validation using `class-validator`.

### 🐳 DevOps
- **Docker Compose:** Fully containerized setup for easy development and deployment.
